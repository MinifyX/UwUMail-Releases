# UwUMail Releases

Downloads and update feeds for [UwUMail](https://github.com/MinifyX/UwUMail-Client), the cute, modern mail
client for everyone. (◕‿◕✿)

## Download

Get **`UwUMail-Setup-<version>.exe`** from the [latest release](../../releases/latest) and run it. UwUMail
installs for your Windows user only, without administrator rights, and keeps itself up to date from then on.

> Windows may show "Windows protected your PC" because the setup isn't code-signed yet. Click **More info** →
> **Run anyway**.

## Deutsch

Lade **`UwUMail-Setup-<Version>.exe`** aus dem [neuesten Release](../../releases/latest) und starte die Datei.
UwUMail wird nur für deinen Windows-Benutzer installiert, ohne Administratorrechte, und hält sich danach selbst
aktuell.

> Windows zeigt eventuell „Der Computer wurde durch Windows geschützt“, weil der Installer noch nicht signiert
> ist. Klicke auf **Weitere Informationen** → **Trotzdem ausführen**.

## What's in here

- [Releases](../../releases) with the Windows setup of every version.
- `stable.json` and `beta.json`: the update feeds UwUMail checks. Every update is signed, and UwUMail only
  installs updates signed with its release key.

This repository only holds finished builds. It's filled automatically when a new version is released.
